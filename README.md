# UIN-Campus
Systeme de gestion academique de l'UIN (projet fil rouge C++23).

## Versions des outils
- g++ 15.2.0
- clang++ 21.1.8
- cmake 4.2.3
- ninja 1.13.2
- gdb 17.1
- git 2.53.0

## Construire
```
cmake --preset debug
cmake --build --preset debug
./build/debug/uin-campus
```
